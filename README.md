# Ktor Task Server

Учебный backend-проект на Kotlin и Ktor.

В проекте реализована работа с задачами и авторизация пользователей через JWT.

## Что реализовано

- регистрация пользователя
- вход по логину и паролю
- хэширование пароля через BCrypt
- JWT-токен
- получение списка задач
- получение задачи по id
- создание задачи
- изменение задачи
- удаление задачи

Создание, изменение и удаление задач требуют JWT-токен.
